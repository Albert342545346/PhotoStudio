# Информационная система «Фотостудия» (КР 1)

Консольное приложение на Java: клиенты фотостудии, залы и бронирования фотосессий.
Данные хранятся в **PostgreSQL**, доступ через **JDBC**, экспорт в **Excel (.xlsx)** и CSV.

```
Console UI  ->  Service  ->  Repository / JDBC  ->  PostgreSQL
 (ui/*)        (service/*)     (repository/*)
```

- **Пакет:** `ru.mirea.photostudio`
- **Java:** 17 или новее
- **Сборка:** Maven (`pom.xml`)
- **Зависимости:** `org.postgresql:postgresql`, `org.apache.poi:poi-ooxml`

## 3. Запуск — пошагово

### Шаг 1. Создать базу данных

**Через pgAdmin:** правой кнопкой по *Databases* → *Create* → *Database…* → имя **`photostudio`** → *Save*.

**Или через командную строку:**

```bash
psql -U postgres -c "CREATE DATABASE photostudio;"
```

### Шаг 2. Выполнить SQL-скрипт

Скрипт создаёт 3 таблицы и заполняет их тестовыми данными (6 клиентов, 4 зала, 12 бронирований).

**Через pgAdmin:** правой кнопкой по базе `photostudio` → *Query Tool* → *Open File* → выберите `sql/photostudio.sql` → нажмите ▶ (F5).

**Или через командную строку:**

```bash
psql -U postgres -d photostudio -f sql/photostudio.sql
```

Скрипт можно запускать повторно: он пересоздаёт таблицы и возвращает данные к исходным
(удобно перед защитой).

### Шаг 3. Указать логин и пароль PostgreSQL

Откройте `src/main/resources/db.properties`:

```properties
db.url=jdbc:postgresql://localhost:5432/photostudio
db.user=postgres
db.password=postgres     <- поставьте свой пароль, заданный при установке PostgreSQL
```

Порт по умолчанию 5432; если у вас другой — измените в `db.url`.

### Шаг 4. Запустить приложение

#### Вариант А — IntelliJ IDEA (рекомендуется)

1. **File → Open** → выберите файл `pom.xml` → **Open as Project**.
2. Дождитесь, пока справа внизу закончится загрузка Maven-зависимостей (нужен интернет при первом запуске).
3. Проверьте JDK: **File → Project Structure → Project → SDK** = 17 или новее.
4. Откройте `src/main/java/ru/mirea/photostudio/Main.java` и нажмите зелёный треугольник ▶ рядом с `main`.
5. В окне *Run* появится главное меню. Вводите номера пунктов и нажимайте Enter.

#### Вариант Б — Maven из командной строки

```bash
mvn compile exec:java
```

#### Вариант В — готовый jar-файл

```bash
mvn clean package
java -jar target/photostudio-1.0.0.jar
```

Если запускаете jar, положите файл `db.properties` **рядом с местом запуска** (в текущую папку) — программа прочитает его оттуда, пересобирать проект после смены пароля не нужно.

> Параметры БД можно также задать переменными окружения `DB_URL`, `DB_USER`, `DB_PASSWORD` — они имеют приоритет.

## 4. Русские буквы в консоли (Windows)

- В **cmd / PowerShell** сначала выполните `chcp 65001`. Если русские буквы при вводе отображаются неправильно, запускайте из IntelliJ IDEA или Windows Terminal.
- Приложение само переключает вывод в UTF-8 и читает ввод в UTF-8.

## 5. Как пользоваться: главное меню

```
============================================================
СИСТЕМА УПРАВЛЕНИЯ ФОТОСТУДИЕЙ
============================================================
1. Клиенты                      — добавить / показать / найти по ID / изменить / удалить
2. Бронирования                 — создать / показать / найти по ID / изменить / сменить статус / удалить
3. Залы студии                  — список залов и цен
4. Поиск                        — по названию, описанию, клиенту, дате
5. Фильтрация                   — по статусу, типу съёмки, диапазону дат, залу
6. Сортировка                   — по дате, цене, клиенту, названию
7. Статистика                   — 14 показателей
8. Экспорт данных               — Excel (.xlsx) и CSV в папку export/
9. Вывести таблицы базы данных  — содержимое всех таблиц «как есть»
0. Выход
```

После каждого действия программа возвращается в меню. Введённые с ошибкой данные не приводят к аварийному завершению — выводится сообщение `Ошибка: ...`.

Файлы экспорта появляются в папке **`export/`** рядом с проектом (`photostudio_ГГГГММДД_ЧЧММСС.xlsx`).

## 6. Сценарий демонстрации на защите (5–7 минут)

Рекомендуемый порядок, чтобы показать все требования КР:

1. **Пункт 9** — покажите таблицы БД (связи `client_id`, `hall_id`).
2. **Пункт 1 → 1** — добавьте клиента. Затем повторите с тем же email → ошибка «уже существует».
3. **Пункт 1 → 3** — введите `abc` → «ID должен быть целым числом»; введите `999` → «не найден».
4. **Пункт 2 → 1** — создайте бронь на будущую дату (например, `27.09.2026 12:00`, 3 часа) — цена посчитается автоматически (выходной тариф +20%).
5. **Нарушения бизнес-правил** (пункт 2 → 1): пустое название; вечер `20:00` на 2 часа; зал `1` на `03.10.2026 11:00` (пересечение); прошедшая дата.
6. **Пункт 2 → 5** — смена статуса: `Создана → Завершена` (запрещено), `Создана → Подтверждена` (можно).
7. **Пункт 2 → 4, 6** — изменение и удаление (удаление завершённой брони запрещено).
8. **Пункты 4, 5, 6** — поиск, фильтрация, сортировка.
9. **Пункт 7** — статистика.
10. **Пункт 8 → 1** — экспорт в Excel, откройте файл из папки `export/`.

Перед защитой заново выполните `sql/photostudio.sql`, чтобы данные были «чистыми».

## 7. Частые проблемы

| Сообщение / симптом | Что делать |
|---|---|
| `Ошибка подключения к базе данных: ... password authentication failed` | Неверный пароль в `db.properties` |
| `Ошибка подключения ... Connection refused` | PostgreSQL не запущен (служба `postgresql-x64-NN`) или другой порт |
| `FATAL: database "photostudio" does not exist` | Не выполнен шаг 1 |
| `ERROR: relation "clients" does not exist` (в меню) | Не выполнен шаг 2 (скрипт) |
| В IDEA красные `import org.postgresql...` | Не загрузились Maven-зависимости: правой кнопкой по `pom.xml` → *Maven* → *Reload project* |
| `Не найдена библиотека Apache POI` при экспорте | То же: обновите Maven-проект |
| `release version 17 not supported` | JDK старее 17 — установите JDK 17+ и выберите его в Project Structure |

## 8. Соответствие требованиям КР 1

| Требование | Где реализовано |
|---|---|
| Консольное меню, возврат в меню после действия | `ui/Menu.java` (цикл `run()`), наследники `MainMenu`, `ClientMenu`, … |
| ≥ 2 связанные сущности | `Client`, `Hall`, `Booking` (`bookings.client_id → clients.id`, `bookings.hall_id → halls.id`) |
| CRUD основной сущности | `BookingService` + `BookingRepository` + `BookingMenu` |
| enum | `BookingStatus`, `SessionType`, `BookingSort` |
| ≥ 5 бизнес-правил в Java-коде | 11 правил в `BookingService`, `ClientService`, `BookingStatus` |
| Обработка ошибок ввода / БД | `ConsoleInput`, `Menu.run()`, `DatabaseManager`, `DatabaseException` |
| ≥ 2 поиска / фильтра / сортировки | 4 поиска (SQL `LIKE`), 4 фильтра (Stream API), 4 сортировки (`Comparator`) |
| Статистика ≥ 5 показателей | `StatisticsService` (14 строк) |
| Экспорт Excel + CSV | `ExcelExporter`, `CsvExporter`, `ExportService` |
| Не всё в Main; слои | пакеты `model / repository / service / ui / util / exception` |
| Инкапсуляция, конструкторы, полиморфизм | `BaseEntity.describe()`, `PricingStrategy`, `Menu` |
| Минимум один интерфейс | `CrudRepository`, `ReadRepository`, `PricingStrategy`, `Titled` |
| Коллекции | `List`, `Map` (`EnumMap`, `LinkedHashMap`), `Optional`, Stream API |
| Собственные исключения | `AppException` и 5 наследников |
| JDBC: Connection, PreparedStatement, ResultSet, try-with-resources | все классы `repository/*` |
| PK, FK, NOT NULL, UNIQUE, CHECK | `sql/photostudio.sql` |
| Тестовые данные (≥5 / ≥10 / ≥3 статуса) | 6 клиентов, 12 броней, 4 статуса и 6 типов |
